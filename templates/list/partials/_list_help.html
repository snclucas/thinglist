Inventory lists — quick help

Overview of lists, visibility, fields and common actions

Lists are collections of related items (for example: retro computers, hobby projects, or tools). Each list has a name and description and can be either private or allow item-level visibility.

Quick actions
  • Add a new list
    Click the icon. Provide a name and description. Choose privacy settings.
  • Privacy vs item-level visibility
    By default lists are private. Enable item-level visibility to allow individual items to be public. Use the icon for private lists and for lists that allow item-level visibility.
  • Move items between lists
    Open an item and choose the destination list to move it. Items retain their fields and attachments when moved.
  • Edit fields and templates
    Lists show default fields such as type, location, tags, and images. You can add or hide fields per list using the Add/Edit list form or manage templates to reuse field combinations.
Still need help? Visit the Settings or the Templates page for field management.
