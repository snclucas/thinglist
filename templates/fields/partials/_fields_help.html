Fields are the information that defines the items in a list. In addition to the default fields avaialble, you can define your own fields to use with your field templates for your lists.

For example:

  • Model
  • Serial number
  • Egg whisk ratio
  • Air speed velocity
  • ...

These fields would then be available to fill in when you add new items to your lists.

User defined fields can be one of a few types:

  • Text - simple text values
  • Bool - true/false
  • Textarea - larger amounts of text
  • Url - validated against and url pattern

You can add a new user field by clicking the icon at the top.

Fields can be deleted by clicking the icon at the top. This will delete the field from the list and all items in the list that use that field.
