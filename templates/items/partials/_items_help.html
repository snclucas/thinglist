Items list — quick reference

Short guide to the item list toolbar and common actions

This view shows items in the current inventory. Use the toolbar icons to add, filter, select and manage items quickly.

{% if is_inventory_owner or inventory_access_level == __COLLABORATOR__ %}
  • Default fields
    Open the default fields control to choose which fields are preselected when creating new items in this inventory.
  • Add new item
    Creates a new item using the inventory's default fields. Fill required fields then save.
  • Delete selected
    Delete one or more items selected via the checkboxes. Deleted items are removed immediately; use caution.
  • Filter list
    Apply filters to narrow results by field values, tags or text. Combine filters for precise searches.
  • Button bar
    Open for more actions such as moving, bulk editing, exporting or changing visibility.
  • Move items
    Move selected items to another inventory; attachments and fields are preserved.
  • Bulk edit
    Edit a field across multiple selected items in one operation.
{% else %}

You have read-only access to this inventory. Contact the owner to request edit permissions.

{% endif %}
